# Writing for everyone

The default viewer is meeting the subject for the first time. Write so that an 8-year-old could
follow, in wording a professional would not find childish. The two goals do not conflict: adults
also follow short sentences and everyday words more easily, and nobody complains that a video
was too clear.

**Simple is not childish.** Childish is baby talk, exclamation marks, forced excitement, cartoon
voices and praise for nothing. Simple is short sentences, common words, one idea at a time, and
an example before a rule. Keep a calm, respectful tone throughout.

A viewer cannot re-read. They hear each line once, at the speaker's speed, while also looking at
a picture. That is why spoken lines must be simpler than written text for the same reader.

## 1. Spoken lines

- **One idea per line.** If a line has "and", "which" or "because" in the middle, see whether it
  is two lines.
- **6 to 14 words is the comfortable range; 20 is the limit.** The checker warns above 24.
- **A line must make sense with the picture off.** Many people listen without watching, and
  captions are read without the voice.
- **Subject first, then verb, then the rest.** "The Moon pulls on the sea", not "The sea, under
  the Moon's pull, …".
- **Put the new thing at the end of the line,** where the voice naturally stresses it. "The path
  it follows is called its *orbit*."
- **No pointing words unless something is pointed at.** "Here", "this box", "as you can see" need
  a ring, an arrow or a spotlight on screen while they are spoken. Better: name the thing ("the
  red bar") and point as well.
- **Say the link out loud.** Use "so", "but", "because", "then" between lines. A viewer does not
  guess how two facts connect. Before each "so", check that every step it depends on was said.
- **Ask real questions, then leave time.** A question followed at once by its answer is not a
  question.
- **Read every line aloud.** If you stumble, run out of breath, or would never say it to a
  person, rewrite it.

## 2. Words

Use the word a child would use when there is one.

| Instead of | Say |
| --- | --- |
| therefore, thus, hence, consequently | so |
| however, nevertheless | but |
| prevent | stop |
| require | need |
| sufficient | enough |
| approximately | about |
| utilize, employ | use |
| obtain, acquire | get |
| demonstrate, illustrate | show |
| commence, initiate | start |
| terminate, conclude | end |
| additional | more, extra |
| assist | help |
| attempt | try |
| purchase | buy |
| numerous | many |
| in order to | to |
| prior to, subsequent to | before, after |
| in the event that | if |
| due to the fact that | because |
| is able to | can |
| a number of | some, several (or the number) |
| occur | happen |
| indicate | show, mean |
| select | pick, choose |
| modify | change |
| remain | stay |
| increase, decrease | go up, go down (or grow, shrink) |

- **One name per thing.** If it is "the path" in line 3, it is not "the route" in line 9 and "the
  track" in line 15. A viewer assumes a new word means a new thing. This matters more than
  elegant variation.
- **The same words on screen and in the voice** for the same thing.
- **Verbs, not nouns made from verbs.** "The price went up", not "there was an increase in price".
- **Name who does what.** "The bank lends the money", not "the money is lent".
- **Positive form.** "Keep the lid on", not "do not fail to keep the lid on". Never two negatives
  in one line.
- **No idioms or figures of speech** that a child or a second-language speaker would take
  literally ("a ballpark figure", "the tip of the iceberg", "under the hood"). A deliberate
  comparison ("think of it like a bathtub filling") is fine when it is introduced as one.
- **No abbreviations** until they have been said in full and shown once. Avoid "e.g.", "i.e.",
  "etc." entirely in speech.

## 3. How a viewer gets confused, and the fix

| What goes wrong | Why it loses the viewer | Fix |
| --- | --- | --- |
| A word is used before it is explained | Everything after it is noise | Explain first, with a word card, or use a plain word instead. |
| A long sentence with several ideas | The first idea is gone by the time the last arrives | One idea per line. Split at "and", "which", "because". |
| Asides in brackets, dashes or sub-clauses | The viewer loses the main sentence | Give the aside its own line, or cut it. |
| Abstract nouns ("efficiency", "accumulation", "volatility") | Nothing to picture | Say what happens, to what: "the hours add up". |
| Idioms and metaphors | Taken literally, or not understood | Say it plainly. |
| Jargon the field uses without noticing | The viewer does not know it is a special word | Replace it, or teach it with a word card. |
| "It", "this", "they" with no clear owner | The viewer picks the wrong one | Repeat the noun. Repetition is fine in speech. |
| Negatives, especially two together | Have to be untangled | State what is, not what is not. |
| Symbols and notation with no words ("Δ", "→", "x²") | Cannot be read aloud in the head | Say it in words when it first appears; show both. |
| Foreign or Latin terms | Unknown | Use the everyday term; give the formal one once if the viewer will meet it. |
| Big numbers, or a sum the viewer cannot check | Taken on trust, then forgotten | Round, compare to something known, and show where each number comes from. |
| A number with nothing to compare it to | No idea if it is big or small | Give the comparison: "about as long as a bus". |
| A missing step before "so" | The conclusion feels like magic | Add the step, however obvious it seems to you. Name who does it. |
| The viewer's sensible guess is never mentioned | They keep the guess, and the true account sounds wrong | Say the guess, then answer it with a reason (`teaching-techniques.md` section 5). |
| Two true lines that seem to contradict ("no wheat goes there" … "wheat can be handed over there") | The viewer believes neither | Read each new line against every earlier line on the same thing. Join them with "but only …". |
| A fixed price that later "goes down"; a rule that later has an exception | Looks like a mistake in the video | Say what is new: "new promises have a lower price than yesterday's". |
| A rule stated in words where examples would do | Rules do not stick without cases | Show two or three examples; state the rule after. |
| Irony, sarcasm, rhetorical questions | Taken as statements, or as real questions | Say what you mean. |
| Passive voice | Hides who does it | Name the doer. |
| Rare or formal words | Cost attention | Use the table in section 2. |
| Too much in one step | Nothing is kept | One new thing per step; pause after it. |
| The same idea under several names | Looks like several ideas | One name per thing. |
| Personal praise or blame ("you're so smart", "the mistake people make") | Sounds false, or talks down | Describe the thing, not the viewer. |
| An example harder than the idea | The example becomes the lesson | Easy example first; the real one after. |
| Two pictures that differ in many ways | The viewer cannot find the change | Change one thing at a time. |

## 4. Numbers

- **Every number on screen or in a sum has a source the viewer has already seen or heard.** If
  the answer uses "6 hours", then "6 hours" appeared earlier. No number arrives from nowhere.
- **Round.** "About 365 and a quarter days" teaches; "365.2422 days" is for the description text
  or a small source line.
- **At most one or two numbers per line.** Three numbers in a line is a table, and belongs on
  screen.
- **Give a comparison** for any number whose size matters.
- **Units every time,** and the same unit throughout. Do not move between minutes and hours
  without saying so.
- **Do sums slowly, in the open:** show the pieces, pause, then show the result. Let the viewer
  try first when the sum is easy.
- **Write spoken numbers as words in the narration and as digits in the caption** (see section 6),
  so the voice reads them correctly and the reader sees digits.
- **Say a number the way it is written.** $1,500 is "one thousand five hundred dollars", not
  "fifteen hundred"; 2,500 is not "two and a half thousand"; 1.5 million is "one and a half
  million" only if the screen shows it that way. A child who is reading the digits must hear
  the same number.
- **Percent, ratios and "times as much"** are harder than they look. Prefer counts: "3 in every
  400", "one of every four".

## 5. New words

A new term is a cost. Each one must earn its place: the viewer will need it later in this video,
or will meet it in the world.

1. **Show the thing first,** then name it. "The path it follows … is called its orbit."
2. **Give it a word card:** the word, large, in the middle of the screen, with its meaning in
   plain words (ten words or fewer if possible), while the voice says the meaning and **nothing
   else changes on screen**.
3. **Define it with words the viewer already has.** Never use another new word in a definition.
4. **Use it again within the next few lines,** the same way, so it settles.
5. **One card per word, once.** Do not show the card again; if a reminder is needed much later,
   say the meaning in passing ("its orbit, the path it follows").
6. **Space them out:** no more than about one new word per minute, and never two close together.
7. If the word is hard to say, give the sound on the card ("say: OR-bit").

Words that look ordinary but are terms in a field ("yield", "function", "culture", "force") need
a card as much as strange ones do. Arguably more: the viewer thinks they already know them.

## 6. Captions

Captions are on by default and are also written to `.srt` and `.vtt` files. Many viewers watch
with the sound off; captions are their narration.

- A caption is the spoken line, unless you give the line its own `caption`.
- **Give a caption with digits** when numbers are spoken as words:
  `v.say('It takes three hundred and sixty-five days.', { caption: 'It takes 365 days.' })`.
  A date is spoken "on the eighth of May" and written "on 8 May", not "on the 8 May". When a
  long script writes both forms from one text with a helper of its own, keep the words that
  belong to one form inside that form: in one video, 205 captions read "the 8 May" because
  "the" sat outside the pair. The checker warns about it in English.
- Long captions are split automatically at sentence and clause boundaries. If one still takes
  three rows, the line is too long.
- Reading speed: the checker warns above 17 characters a second (half that for Chinese, Japanese
  and Korean text). Shorten the line or slow the voice.
- Use `caption: false` only for a line that is already fully written on screen (a word card's
  meaning, a quote).
- Keep the bottom of the picture clear for them (see `visual-design.md`).

## 7. Text on screen

- **Short.** A heading is a few words. A label is one to three. If it needs a full sentence, the
  voice should say it and the screen should show the key words.
- **The viewer reads or listens, not both.** Do not show a paragraph while the voice says
  something different. Do not show the full narration as on-screen text either (captions already
  do that); show the three words that matter.
- **Same words as the voice** for the same thing.
- **`**strong**`** marks the one word a text is about. It is drawn in the accent colour. One per
  text, at most.
- **Sentence case.** Capitals for whole words are harder to read.
- **Leave it up long enough to read twice:** roughly one second plus a third of a second per word.
  The checker warns when a text is replaced sooner.

## 8. Tone

- Calm and plain. State things; do not sell them.
- Talk to one viewer ("you"), or use "we" for things done together ("we add one day").
- No hype words: "amazing", "incredible", "mind-blowing", "simply", "just", "obviously", "of
  course". The last four tell a confused viewer it is their fault.
- No praise for the viewer and no blame for people who get it wrong. Describe the common wrong
  idea neutrally: "it is easy to think … but".
- Humour only if it survives translation and does not need to be explained.
- Be honest about limits: "about", "usually", "one reason is". A careful "about" is more
  professional than a false exact figure.

## 9. What the checker measures

`node tools/check.mjs <id>` warns about the parts of this file that can be counted:

| Warning | Meaning | Option to change the limit |
| --- | --- | --- |
| *N words in one line* | A line over 24 words | `--max-words 24` |
| *says "…" but nothing is pointed at* | A pointing phrase with no pointer on screen | |
| *N characters a second* | A caption too fast to read | `--cps 17` |
| *reads at about grade N* | Sentence and word length of the whole narration (English only) | `--grade 8` |
| *long sentence* | The longest sentences | |
| *the voice talks at N words a minute* | Over 200 while speaking | set `voice.rate` |
| *N words a minute overall* | Over 165 including pauses; aim for 120 to 150 | |
| *"…" is on screen N s* | A text replaced before it could be read | |
| *the quotation "…" was already spoken* | The same quoted words (five or more) spoken twice, over half a minute apart | |
| *"word" is said … before its word card* (error) | A term used before it was taught | |
| *two new words within N s* | Word cards less than 15 seconds apart | |

The checker counts; it does not understand. A script can pass every count and still lose the
viewer at a missing step. That is what the comprehension review is for (`script-review.md`).
