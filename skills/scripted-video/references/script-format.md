# The script format

A video is one plain-data object: no functions, no code. It can be written by hand as JSON
(`videos/<id>.json`), produced by the authoring kit (`videos/<id>.mjs`, see `authoring-kit.md`), or
generated by any program. The tools, the player and the exporter all read this format.

Use the kit for anything longer than a few lines: it keeps the timing references and the layout
arithmetic for you. Read this file when you need to write JSON by hand, generate scripts from
another program, read a dump, or understand an error message that quotes a path such as
`/tracks/0/clips/2/commands/1/at`.

## 1. A whole script

```json
{
  "format": "video-script",
  "version": 1,
  "id": "plant",
  "title": "How a plant makes its food",
  "stage": { "width": 1920, "height": 1080, "fps": 30, "background": "#0b1626" },
  "assets": { "plant": "assets/example/plant.svg", "pop": "assets/example/pop.wav" },
  "tracks": [
    {
      "id": "base",
      "kind": "visual",
      "clips": [
        {
          "id": "heading",
          "module": "text",
          "start": "@start",
          "box": { "x": 115, "y": 60, "w": 1690, "h": 170 },
          "props": { "text": "How a plant makes its food", "role": "title" },
          "in": "slide-up"
        },
        {
          "id": "picture",
          "module": "image",
          "start": "@needs-0.3",
          "box": { "x": 460, "y": 250, "w": 1000, "h": 640 },
          "props": { "src": "plant", "fit": "contain" }
        }
      ]
    },
    {
      "id": "overlay",
      "kind": "visual",
      "clips": [
        {
          "id": "marks",
          "module": "annotate",
          "start": "@needs",
          "commands": [
            { "id": "ringLeaf", "at": "@leaf", "name": "point",
              "args": { "target": { "clip": "picture", "rect": [0.53, 0.37, 0.26, 0.23] }, "style": "ring", "label": "leaf", "side": "right" } },
            { "at": "@leaf.end+0.4", "name": "clear", "duration": 0.25 }
          ]
        }
      ]
    },
    {
      "id": "voice",
      "kind": "narration",
      "segments": [
        { "id": "hi", "text": "A plant makes its own food.", "gap": 1 },
        { "id": "needs", "text": "It needs three things: sunlight, water and air." },
        { "id": "leaf", "text": "The leaves catch the sunlight.", "gap": 0.8 }
      ]
    },
    {
      "id": "sound",
      "kind": "audio",
      "clips": [{ "src": "pop", "start": "@ringLeaf", "volume": 0.5 }]
    }
  ],
  "markers": [{ "kind": "chapter", "at": "@start", "label": "How a plant eats" }]
}
```

`videos/hello.json` in the starter is this video with two languages and a vertical layout.

## 2. Top-level fields

| Field | Default | Meaning |
| --- | --- | --- |
| `format` | required | Always `"video-script"`. |
| `version` | | `1`. |
| `id` | `"video"` | Names the output files. Keep it equal to the file name. |
| `title` | | A text (section 9). Used for the mp4's title. |
| `stage` | section 3 | Size, frame rate, colours, captions. |
| `defaultLanguage` | `"en"` | The language the script's own texts are in. |
| `tracks` | required | Visual, narration and audio tracks (sections 5 to 7). |
| `markers` | | Chapters, pauses, cues, notes (section 8). |
| `assets` | | `{ key: path }`: names for files. Paths are from the project folder. |
| `fonts` | | `[{ family, src, weight?, style? }]`: font files to load. |
| `strings` | | `{ language: { key: text } }` (section 9). |
| `layouts` | | Other shapes of the same video (section 10). |
| `voice` | | Voice settings for every line (see `voice-and-assets.md`). `rate` also scales the estimated line length. |
| `speakers` | | `{ name: { voice: {…} } }`. |
| `pronunciations` | | `[{ text, say, language?, matchCase? }]`: what the voice reads in place of a written form. |
| `gap` | `0.5` | Seconds of silence before each line. |
| `pace` | | Estimated speaking speed until a voice is measured: `wordsPerSecond` (2.75), `charsPerSecond` (4.5, Chinese characters), `kanaPerSecond` (7), `hangulPerSecond` (6), `thaiPerSecond` (13). |
| `duration` | | A fixed length (a time). Required only when there is no narration. |
| `tail` | `2` | Seconds after the last line ends. |

## 3. The stage

```json
"stage": {
  "width": 1920, "height": 1080, "fps": 30, "background": "#0b1626",
  "fontFamily": "\"Atkinson Hyperlegible\", sans-serif",
  "theme": { "accent": "#ffcf3f", "card": "#1b3354" },
  "caption": { "show": true, "maxUnits": 84 }
}
```

| Field | Default | Meaning |
| --- | --- | --- |
| `width`, `height` | 1920 × 1080 | The stage in its own units. All boxes are in these units; the picture is scaled to whatever size is exported. |
| `fps` | 30 | Frames a second. |
| `background` | `#000000` (the kit uses `#0b1626`) | A CSS colour. |
| `fontFamily` | system fonts | For all text. |
| `theme` | | Any of `ink`, `dim`, `accent`, `accentInk`, `card`, `good`, `bad`, `font`, `mono` (see `visual-design.md`). |
| `caption.show` | `true` | `false` draws no captions on the picture (subtitle files are still written). |
| `caption.maxUnits` | 84 | Longest caption before it is split; a wide (East Asian) character counts 2. |
| `caption.bottom` | 4.5% of the height | Distance of the caption from the bottom edge. |
| `caption.width` | 0.86 | Widest caption, as a share of the stage width. |
| `caption.size` | 3.8% of the short side | Caption text size. |

## 4. Times and references

Anywhere a time is expected you can write:

| Form | Example | Meaning |
| --- | --- | --- |
| A number | `12.5` | Seconds. |
| A timecode | `"1:05.25"`, `"1:02:03"` | Minutes:seconds, or hours:minutes:seconds. |
| A reference | `"@leaf"` | The moment something with that id starts. |
| | `"@leaf.end"` | The moment it ends. |
| | `"@leaf+1.5"`, `"@leaf-0.25"` | Seconds after or before its start. |
| | `"@leaf.end+0.5"` | Seconds after its end. |
| | `"@leaf+40%"` | 40% of the way from its start to its end. |
| | `"@start"`, `"@end"` | The start and end of the video. |

Anything with an `id` can be referred to: a narration line, a clip, a command, a sound, a marker.

Ids may contain `-`. `"@leaf-2"` therefore means the thing called `leaf-2` when there is one,
and two seconds before `leaf` when there is not; `"@leaf - 2"` and `"@leaf.start-2"` always mean
the second. Only one offset may follow a reference.

The tools take the same three forms on the command line: `--at "12.5,1:05,@leaf.end"`,
`--from @n4 --to "@n6.end"`, `--thumbnail "@n5+50%"` (quote them in a shell).

**What a plain number counts from:**

| Where | A number or timecode counts from |
| --- | --- |
| A clip's or sound's `start`, `end`; a line's `start`; a marker's `at`; `duration` | The start of the video |
| A command's `at` and `until`; a keyframe's `at` | The start of **its clip** |

A reference is always an absolute moment, wherever it is written.

**Prefer references to numbers.** A script built on line references keeps its timing when the
wording changes, when a real voice replaces the estimate, and in every language. A script built
on numbers has to be re-timed by hand each time.

Rules:

- Ids are letters, digits, `_` and `-`, starting with a letter or `_`. `start` and `end` are
  taken. Every id in a script is unique across lines, clips, commands, sounds and markers.
- One offset per reference: `"@leaf+40%+1"` is an error. Give the first thing an id and refer to
  that: `"@ringLeaf+1"`.
- References may point forwards or backwards, but not in a circle (*circular time reference*).

## 5. Visual tracks and clips

```json
{ "id": "base", "kind": "visual", "clips": [ … ] }
```

Tracks are drawn in order: the first track is at the back. Within a track, later clips are over
earlier ones. Put pointing (`annotate`) and cards on later tracks.

A clip:

| Field | Default | Meaning |
| --- | --- | --- |
| `id` | required | Its name. |
| `module` | required | The component: `text`, `scene`, `image`, … (see `components.md`). |
| `start` | `0` | When it appears. |
| `end` or `duration` | the end of the video | When it leaves. |
| `minDuration` | | "Never shorter than this": the clip lasts until `end`, or this long, whichever is later. |
| `box` | the whole stage | `{ x, y, w, h }` in stage units. Missing parts take the stage's. |
| `props` | `{}` | The component's starting props. |
| `commands` | | Changes over time (below). |
| `keyframes` | | Movement of the clip as a whole (below). |
| `in`, `out` | none | Transitions (below). |
| `opacity`, `scale`, `rotate` | `1`, `1`, `0` | Of the whole clip. `rotate` is in degrees. |

**Commands** change what the component shows:

```json
{ "id": "grow", "at": "@n4", "name": "reveal", "args": { "count": 3 }, "duration": 0.8, "ease": "out" }
```

| Field | Meaning |
| --- | --- |
| `at` | When it starts (default: when the clip starts). |
| `name`, `args` | Which command, with what. Each component lists its own. |
| `duration` | Seconds it takes. `0` or absent: at once. |
| `until` | Instead of `duration`: the moment it finishes. |
| `ease` | The curve (default `inOut`). |
| `id` | Optional, so other things can refer to it. |

Commands are applied in time order. A command timed outside its clip's life is a warning.

**Keyframes** move, resize, fade, scale or turn the clip:

```json
"keyframes": {
  "scale": [{ "at": "@needs", "value": 0.92 }, { "at": "@end", "value": 1, "ease": "out" }],
  "opacity": [{ "at": 0, "value": 0.3 }, { "at": 1.5, "value": 1 }]
}
```

Properties: `x`, `y`, `w`, `h`, `opacity`, `scale`, `rotate`. Before the first keyframe the value
is the first keyframe's; after the last, the last one's. Each keyframe's `ease` shapes the
approach to it.

**Transitions.** `"in"` and `"out"` are a name or `{ "type", "duration", "ease" }` (0.4 seconds
and `out` by default):

`fade`, `slide-up`, `slide-down`, `slide-left`, `slide-right` (a short slide with a fade), `zoom`,
`wipe`, `cut` (none).

**Easing names.** `linear`, `hold` (jump at the end), `in`, `out`, `inOut`; `inSine`, `outSine`,
`inOutSine` and the same three for `Quad`, `Cubic`, `Quart`, `Expo`, `Back`; `pop` (a small
overshoot); `cubic-bezier(x1, y1, x2, y2)`.

## 6. Narration tracks

```json
{
  "id": "voice",
  "kind": "narration",
  "segments": [
    { "id": "n1", "text": "The Earth takes one year to go around the Sun.", "gap": 1 },
    { "id": "n2", "text": "That is three hundred and sixty-five days.", "caption": "That is 365 days." }
  ]
}
```

| Field | Default | Meaning |
| --- | --- | --- |
| `id` | required | Recordings, timings and references use it. Do not renumber the lines of a video that already has a recorded voice or translations. |
| `text` | required | What is said. |
| `caption` | the text | What the caption shows, or `false` for none. |
| `gap` | the track's, then the script's, then 0.5 | Silence before the line. |
| `start` | after the previous line and the gap | A fixed moment instead. |
| `speaker` | | A name from `speakers`. |
| `voice` | | Settings for this line only. |
| `audio` | | A recording to use for this line (a path), instead of a generated voice. |

A track may also have `gap` and `voice` for all of its lines. A line lasts as long as its
recording; until one exists the length is estimated from the words (about 165 words a minute).
Lines of one track that overlap are a warning. Two narration tracks may overlap on purpose.

Captions are made from the lines: split at sentence ends, then at commas, when longer than
`maxUnits`; each stays for its share of the line, plus a moment after.

## 7. Audio tracks

```json
{
  "id": "sound",
  "kind": "audio",
  "clips": [
    { "src": "bed", "start": "@start", "end": "@hi", "volume": 0.5, "fadeOut": 0.6, "duck": true },
    { "src": "pop", "start": "@ringLeaf", "volume": 0.5 }
  ]
}
```

| Field | Default | Meaning |
| --- | --- | --- |
| `src` | required | An asset key or a path. |
| `start` | `0` | When it begins. |
| `end` or `duration` | the file's length | When it stops. |
| `from` | `0` | Seconds into the file to begin at. |
| `volume` | `1` | 0 to 1. Music under a voice: 0.15 to 0.25. |
| `loop` | `false` | Repeat until `end`. |
| `fadeIn`, `fadeOut` | `0` | Seconds. |
| `duck` | `false` | Lower it while a narration line is spoken. |
| `id` | | Optional. |

## 8. Markers

```json
"markers": [
  { "kind": "chapter", "at": "@start", "label": "The question" },
  { "kind": "chapter", "at": "@n9-0.2", "label": "The fix" },
  { "kind": "pause", "at": "@think1-ask.end", "label": "After four years, how many hours?" },
  { "kind": "note", "at": "@n4", "label": "needs asset: harbour photo" }
]
```

| Kind | Used for |
| --- | --- |
| `chapter` | Chapters in the mp4, the `.chapters.txt` file and the player. The first belongs at 0:00. |
| `pause` | Where the thinking time of a question starts: just after the narrator has read the question aloud. An interactive player can stop here. |
| `cue` | A moment an editor or another program should know about. |
| `note` | For the people making the video. Never shown. |

## 9. Texts and languages

Any text (in `props`, command `args`, narration, captions, marker labels, the title) may be:

| Form | Meaning |
| --- | --- |
| `"A plain string"` | Used in every language. Right for a video in one language, and for things that are not translated (code, numbers, names). |
| `{ "$t": "key" }` | Looked up in `strings`. |
| `{ "$t": { "en": "leaf", "es": "hoja" } }` | Translations written in place. |

```json
"defaultLanguage": "en",
"strings": {
  "en": { "hi": "A plant makes its own food." },
  "es": { "hi": "Una planta fabrica su propio alimento." }
}
```

For a language such as `fr-CA` the lookup tries `fr-CA`, then `fr`, then the default language. A
text found only in the default language is used, and listed as **untranslated**: `check` reports
it as an error for that language. A key found nowhere is an error.

Translation files next to the videos (`videos/i18n/<id>.<lang>.json`) are merged into `strings`
by the tools; see `localization.md`.

## 10. Layouts

A layout is the same video in another shape (vertical for phones, square), with the same script,
voice and timing:

```json
"layouts": {
  "vertical": {
    "width": 1080, "height": 1920,
    "clips": {
      "heading": { "box": { "x": 70, "y": 200, "w": 940, "h": 300 } },
      "picture": { "box": { "x": 40, "y": 600, "w": 1000, "h": 640 } },
      "logo": { "hidden": true },
      "chart1": { "props": { "title": "Rain" } }
    }
  }
}
```

A layout may set `width`, `height`, `background`, and for any clip a new `box` (merged over the
clip's own), extra `props` (merged), or `hidden: true`. Clips it does not mention keep their box,
so in a different shape every clip normally needs an entry. Tools take `--layout vertical`.
Keyframes on `x`, `y`, `w`, `h` are not adjusted by a layout; avoid them on clips that a layout
moves.

## 11. How the length is worked out

1. Each line starts when the line before it ends, plus its gap (or at its own `start`).
2. Each line lasts as long as its recording, or the estimate.
3. The video ends `tail` seconds after the last line ends, or at `duration` if given; and never
   before the last clip ends.
4. Clips with no end last to the end of the video.

So recording the voice changes the length of the video, and everything tied to lines by
reference follows. After recording, run `check` and look at the stills again.

## 12. Using the engine from code

The engine is three pure functions and a renderer:

```js
import { compile, ScriptError, frameTimes } from './engine/compile.js';
import { evaluate, subtitleCues, toSrt, toVtt } from './engine/evaluate.js';
import modules from './modules/index.js';

try {
  const timeline = compile(script, { modules, language: 'en', layout: null, durations: {} });
  const frame = evaluate(timeline, 12.5);     // everything on screen at 12.5 s
} catch (e) {
  if (e instanceof ScriptError) for (const i of e.issues) console.log(i.path, i.message);
}
```

- `compile` checks the script, resolves every time to seconds, and works out the state of every
  clip after each command. All problems are thrown together as one `ScriptError` whose `issues`
  are `{ severity, path, message }`. `durations` is `{ lineId: seconds }` from the recorded voice.
- The **timeline** has `duration`, `fps`, `stage`, `layers`, `segments` (lines with `start`,
  `end`, `text`), `captions`, `sounds`, `markers`, `chapters`, `untranslated` and `issues`
  (warnings).
- `evaluate(timeline, t)` returns the **frame**: `{ time, layers, caption, chapter, line }`. It
  is a pure function of the time, so any moment can be drawn without playing up to it.
- `frameTimes(timeline, [from, to])` lists the time of every frame.
- In a browser, `createRenderer(container, { modules })` from `engine/web/renderer.js` draws
  frames into a page, and `createPlayer(container, { script, modules, … })` from
  `engine/web/embed.js` adds a clock and sound on top of it. `node tools/bundle.mjs <id>` packs a
  video with both for a web page or an app: see `export-and-publish.md` section 9.

`node tools/dump.mjs <id>` prints the compiled timeline as a readable table: every line with its
time, and every clip and command under the line it happens in.
